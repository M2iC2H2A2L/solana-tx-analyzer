# Solana TX Analyzer

Python tool to fetch and analyze Solana transactions via RPC. Uses solana-py for on-chain data.

## Features
- Fetch tx details.
- Basic analysis: fees, balances, instructions count.
- Pandas for data output.

## Setup
1. `pip install -r requirements.txt`
2. Run: `python analyzer.py <tx_signature>`

Example: `python analyzer.py 5s4m...` (use a real sig from Solscan).
